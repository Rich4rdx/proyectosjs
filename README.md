# 🧩 Proyectos de JavaScript

Tres mini aplicaciones hechas con **JavaScript puro**, sin frameworks, para practicar la manipulación del DOM y los eventos.

![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?style=flat&logo=javascript&logoColor=black)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat&logo=css3&logoColor=white)

| Proyecto | Qué hace | Demo |
|---|---|---|
| [Lista de tareas](javaScript/) | Agregar tareas, marcarlas como completadas y eliminarlas. Valida que el campo no esté vacío | [Ver](https://rich4rdx.github.io/proyectosjs/javaScript/) |
| [Contador](contador/) | Sumar, restar y reiniciar. El número cambia de color si es positivo, negativo o cero | [Ver](https://rich4rdx.github.io/proyectosjs/contador/) |
| [Catálogo](catalogo/) | Catálogo de productos construido completamente desde JavaScript, con buscador y contador de carrito | [Ver](https://rich4rdx.github.io/proyectosjs/catalogo/) |

## Qué practiqué

- Seleccionar y crear elementos del DOM (`getElementById`, `createElement`, `appendChild`)
- Escuchar eventos con `addEventListener`
- Cambiar clases y estilos según el estado de la aplicación
- Validar lo que escribe el usuario

## Cómo verlos

Clona el repositorio y abre el `index.html` de cada carpeta en el navegador.
